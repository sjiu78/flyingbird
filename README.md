# FlyingBird subscription tools

Install: `python -m pip install -r requirements-subscribe.txt`

Run: `python get_subscribe.py account@example.invalid`

Windows: `python get_subscribe.py account@example.invalid --platform windows`

Password uses a hidden prompt. See [usage](docs/get-subscribe-usage.md) and [protocol methods](docs/flyingbird-3.1.8-subscription-method.md).
